# Тестирование и результаты проверки

Проверка: 14 октября 2026. Команда: `npm run test:ci` (PowerShell: `npm.cmd run test:ci`).

55 тестов в 8 наборах. Покрытие: statements 83,15%, branches 72,81%, functions 87,95%, lines 87,55%.
Минимальные пороги: 80/70/80/85% соответственно. HTML-отчёт после запуска: `coverage/lcov-report/index.html`.

## Что проверяется

- Все объявленные маршруты: главная и её разделы, списки, каждый эксперт и событие, услуга, редиректы неизвестных slug.
- Мобильное меню, выбор тарифа, ввод в форму, открытие/закрытие чата, FAQ, варианты подарочной карты, запуск Vimeo.
- Desktop/mobile фотогалерея, точки и свайпы галереи с текстом, слайдер эксперта: задержка перехода, обратное движение, отмена свайпа, выход из слайдера, удаление listeners.
- Reducer, валидация навигации, wheel/touch, вложенная прокрутка, контекст и анимации, вспомогательные компоненты, web-vitals.
- В тестах используется настоящий React Router и Framer Motion. В существующем изолированном тесте слайдера эксперта содержимое слайда заменено mock-компонентом. JSDOM не реализует прокрутку, поэтому scrollTo/scrollIntoView заменены функциями-наблюдателями.

## Исправленные ошибки

1. **Мобильная PhotoSlider:** CSS показывал одно фото, но JS использовал шаг 1/3 и останавливался за два фото до конца. Число видимых фото теперь зависит от ширины, пересчитывается при resize; индекс ограничивается при изменении списка/ширины. Регрессионный тест воспроизводил `-66.66%` вместо `-400%` на пяти фотографиях.
2. **Service:** относительный `to="headshots"` из `/` вёл на отсутствующий `/headshots`. Ссылка теперь абсолютная `/service/headshots`.
3. **useNavigator:** `NaN` и дробные индексы попадали в состояние, оставляя слайдер без активной страницы. Добавлена проверка целых чисел для обоих индексов.
4. **useWheel:** обработанное вложенной галереей wheel-событие переключало также основную страницу. Теперь учитывается `defaultPrevented`; регрессионный тест до исправления фиксировал лишний вызов next.
5. Исправлено окружение тестов: устаревший шаблонный App.test заменён сценариями приложения; добавлены явные пути модулей React Router для Jest 27 и TextEncoder/TextDecoder для JSDOM.

Дополнительно удалён дублирующий ref чата, добавлено имя кнопки отправки для доступности и убран отладочный вывод ref в ServiceCard.

## Зависимости

Полный результат `npm audit --json`: [audit-results.json](audit-results.json).
Реестр сообщил 101 уязвимый пакет: 4 critical, 40 high, 43 moderate, 14 low. Это количество пакетов по классификации npm, а не доказанных эксплойтов сайта.

Четыре critical находятся в цепочке `react-scripts@5.0.1` (проверено `npm ls ... --all`):

- `form-data@3.0.1`: Jest → jsdom; [advisory](https://github.com/advisories/GHSA-fjxv-7rqg-78g4).
- `proxy-addr@2.0.7`: webpack-dev-server → express; [advisory](https://github.com/advisories/GHSA-jqcg-44mw-7w3h).
- `shell-quote@1.8.1`: react-dev-utils и launch-editor; [advisory](https://github.com/advisories/GHSA-w7jw-789q-3m8p).
- `websocket-driver@0.7.4`: webpack-dev-server → sockjs; [advisory](https://github.com/advisories/GHSA-xv26-6w52-cph6).

React Router также помечен high. В данном коде используется BrowserRouter; серверные RSC/SSR сценарии из части advisories здесь не обнаружены. Эксплуатируемость отдельно не проверялась. Автоматический `npm audit fix --force` не применялся; обновление цепочки сборки требует отдельной проверки совместимости.

## Границы проверки

Не заявляется 100% покрытие или отсутствие ошибок. Дополнительная проверка в браузерах и мобильной эмуляции описана в [BROWSER_TESTING.md](BROWSER_TESTING.md); она подтвердила проблему touch-прокрутки FAQ. Проверки на физических устройствах и сетевой доставки сообщений нет. Точка входа index.js исключена из покрытия; пустой ScrollImages.js и barrel-экспорты не имеют исполняемых сценариев. Скрипт оптимизации изображений не запускался, чтобы не перезаписывать ассеты. Тестовая библиотека выдаёт предупреждение deprecated act, сборщик — предупреждения об устаревшей Browserslist и зависимости Babel.
