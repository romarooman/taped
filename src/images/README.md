# Изображения проекта

- `brand/` — логотип, wordmark, логотипы партнёров.
- `icons/` — стрелки и графика чата.
- `studio/` — фасад и карта студии.
- Для реальных изображений услуг создавайте, например, `services/headshots/`.
- `placeholders/` — существующие тестовые фото, ранее `1.webp`–`9.webp`. Названия отражают первоначальную роль на главной, а не подтверждённую личность человека на фото.

Новые реальные портреты размещайте в `people/<person-slug>/`, фотографии событий — в `events/<event-slug>/`. Создавайте папки по мере появления файлов. Один исходный веб-ассет хранится один раз, даже если используется на нескольких страницах.

Прежние `service.webp` и `1.webp` были побайтно одинаковыми; теперь оба сценария используют `placeholders/home-hero.webp`.

Имена: латиница, нижний регистр, дефисы. Примеры: `portrait.webp`, `studio-exterior.webp`, `session-01.webp`. Порядок отображения определяет массив в данных, а не имя файла.

## Где менять содержание

| Данные | Назначение |
| --- | --- |
| `src/data/homeData.js` | Изображения секций главной и порядок слайдов с цитатами |
| `src/data/servicesData.js` | Обложка услуги, превью видео, галерея, тарифы |
| `src/data/expertsData.js` | Карточки экспертов и изображения разделов интервью |
| `src/data/communityData.js` | Карточки и страницы событий |
| `src/data/studioData.js` | Общие изображения студии и карты |
| `src/data/imagePlaceholders.js` | Только общие временные изображения и их описания |

Не меняйте общий placeholder ради одной страницы: импортируйте реальное фото в соответствующий файл данных и замените конкретную ссылку.

```js
import portrait from "../images/people/max-ishchenko/portrait.webp";

// В записи эксперта:
image: {
  src: portrait,
  alt: "Portrait of Max Ishchenko",
  objectPosition: "center 30%", // Необязательно; без него действует существующий CSS.
}
```

`Image` в `src/Components/Image/Image.js` отображает эти записи. Он также принимает строковый URL для иконок и совместимости с существующими props. Alt из записи имеет приоритет над запасным alt компонента; для декоративного изображения укажите `alt: ""`. Текст сайта сейчас английский, поэтому описания изображений тоже английские.

У PhotoSlider запись плоская: `{ id: "session-01", src, alt, objectPosition }`. У экспертов, событий и слайдов с цитатами объект находится в поле `image`. ID элемента галереи должен быть уникальным, даже если изображение повторяется.

## Подготовка файлов

В `src/images` храните подготовленные для сайта версии. Полноразмерные оригиналы держите вне каталога исходников сайта. Приложение использует явные импорты, поэтому сборщик проверяет наличие файлов и формирует URL ассетов.

`npm run optimize:images -- --dry-run` показывает PNG больше 100 КБ, для которых будет создан WebP. Без `--dry-run` скрипт рекурсивно обходит подпапки и создаёт WebP рядом с PNG; существующий WebP не перезаписывает. Оригиналы не удаляет и импорты автоматически не переключает.

Для массовой замены: добавьте файл, обновите соответствующие данные, проверьте кадрирование и выполните `npm run test:ci` и `npm run build`.
